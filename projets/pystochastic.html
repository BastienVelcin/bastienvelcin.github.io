01 — Aperçu

Aperçu

PyStochastic est une bibliothèque Python pensée comme une boîte à outils unifiée pour le calcul stochastique et la modélisation stochastique: plutôt que de réimplémenter un générateur de mouvement brownien ou un schéma d'Euler-Maruyama à chaque projet, chaque brique (processus, EDS, statistiques, filtrage) est disponible sous une interface commune.

Le projet est encore en développement actif (WIP) : les modules ci-dessous décrivent l'architecture visée et l'état actuel du dépôt.

04 — Simulation

Monte Carlo & Équations Différentielles Stochastiques

La simulation de Monte Carlo consiste à générer un grand nombre de trajectoires indépendantes d'un même processus pour estimer une quantité d'intérêt (prix, probabilité, espérance) par une moyenne empirique.

Pour les processus définis par une équation différentielle stochastique sans solution explicite, PyStochastic propose deux schémas de discrétisation : Euler-Maruyama (ordre faible 1) et Milstein, qui ajoute un terme correctif pour une meilleure précision lorsque la diffusion dépend de l'état. 

from sde.eulermaruyama import EulerMaruyama

# Drift function 
def drift(x,t):
       return t*x

# Diffusion function, 
def diffusion(x,t):
       return 2

# Solving dX_t = drift(X_t, t)dt + diffusion(X_t,t)dW_t, 
X = EulerMaruyama(mu=drift, sigma=diffusion, x_0=0, t_0=0, t_n=1, n_steps=1000, n_simulations=20)
X.solve(plot=True)
