Guide

Installation

La version actuelle de PyStochastic n'est pas encore publié sur PyPI. En attendant, installez-le directement depuis GitHub :

git clone https://github.com/BastienVelcin/PyStochastic.git
cd PyStochastic
pip install -e .

Une distribution stable sur PyPI fait partie des prochaines étapes du projet.

Guide

Démarrage rapide

Exemple introductif : simulation d'un mouvement brownien et affichage de quelques de ses trajectoires.

from pystochastic.processes.brownian import Brownian

W = Brownian(var=1, t_0=0, t_1=1, n_steps=1000)
W.simulate(n_simulations=20)
dW = W.increments

W.plot()
