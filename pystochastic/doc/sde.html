pystochastic.sde

Schémas de discrétisation pour les équations différentielles stochastiques sans solution explicite.

pystochastic.sde

EulerMaruyama

Schéma d'Euler-Maruyama : discrétisation d'ordre faible 1, la méthode de référence pour simuler une EDS.

class pystochastic.sde.EulerMaruyama(process, dt, n_steps)

Paramètres

  • processobject

    instance de processus définissant la dérive et la diffusion.

  • dtfloat

    pas de temps de la discrétisation.

  • n_stepsint

    nombre de pas de temps.

EulerMaruyama.simulate

.simulate(n_paths=1, seed=None)

ndarraytableau de forme (n_paths, n_steps).

Exemple

process = OrnUhl(theta=1.2, mu=0, sigma=0.5)
scheme  = EulerMaruyama(process, dt=0.01, n_steps=1000)
trajectoires = scheme.simulate(n_paths=200)
